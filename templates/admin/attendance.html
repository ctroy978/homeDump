Upload class roster

Upload the Perm ID, Student Name CSV for one class. This is the full class list used for named worksheets. Attendance reports only include students who have been absent.

Choose the period, then upload a CSV with columns named Perm ID and Student Name (Last, First). Students in this file become the active roster for that period. Students who leave the class drop off the next roster upload; their old absences stay for leftover makeup.

Upload Attendance

Upload a year-to-date attendance export for one class at a time (.txt or .xlsx). Tell the app which period this class is. Only that period’s absence column is imported — other periods in the file are ignored.

Each student is identified by student ID (SIS number) only. Students in this file are recorded as having you that period. An attendance upload does not remove students who were not absent — use the class roster upload above to set who is in the class. If a student moves to another of your periods, upload that class roster and tag the new period.
