Upload Attendance

Upload a year-to-date attendance export for one class at a time (.txt or .xlsx). Tell the app which period this class is. Only that period’s absence column is imported — other periods in the file are ignored.

Each student is identified by student ID (SIS number) only. Students in this file are recorded as having you that period. Students who leave the class stay in the database so they can still request makeup for days they missed while enrolled. If a student moves to another of your periods, upload that class export and tag the new period.
